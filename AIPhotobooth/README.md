# AI Photobooth

A modern, fully responsive frontend for an AI photobooth using React.js, designed to guide users through an engaging and visually rich experience.

## Features

- **Engaging User Flow**: Start page with carousel, gender selection, style selection, photo capture, and results
- **Modern UI**: Beautiful interface with smooth transitions, animations, and a responsive design
- **Interactive Components**: Hover effects, interactive elements, and realistic photo capture experience
- **Trending Styles**: Feature highlighting popular transformation styles
- **Style Details**: Comprehensive information about each transformation style
- **Social Sharing**: Options to share transformations on various platforms
- **Favorites**: Save your favorite styles for quick access

## Technology Stack

- React.js
- Framer Motion for animations
- Tailwind CSS for styling
- Lucide React for icons

## Getting Started

1. Clone this repository
2. Install dependencies:
   ```
   npm install
   ```
3. Run the development server:
   ```
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

- `/src/components` - React components
  - `/ui` - Reusable UI components
  - `/layout` - Layout components (Header, Footer, etc.)
  - `/pages` - Page components for each step of the process
- `/src/styles` - CSS styles
- `/src/data` - Data files
- `/src/assets` - Images, videos, and other assets
